# Exploratory Data Analysis (EDA) Project

Analysis of the Titanic dataset to uncover patterns, correlations and key factors influencing survival.

## What's inside
- `EDA_Project.ipynb`: full analysis (cleaning, statistical summaries, visualizations, correlations, insights)
- `requirements.txt`: Python dependencies

## Techniques used
- Handling missing values, duplicates and outliers
- Statistical summaries
- Univariate, bivariate and correlation analysis (Pandas, Matplotlib, Seaborn)
- Structured report of insights

## Run it
```bash
pip install -r requirements.txt
jupyter notebook EDA_Project.ipynb
```

## Key findings
Sex, passenger class and age were the strongest factors affecting survival.
